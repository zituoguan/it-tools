nano快捷键概览      
=====================================

# 编辑器按键及其功能         

## 文件操作

| 快捷键 | 描述 |
|:--|:--|
| Ctrl+S | 保存当前文件 |
| Ctrl+O | 提供写入文件选项（"另存为"） |
| Ctrl+R | 将文件插入到当前文件中 |
| Ctrl+X | 关闭缓冲区，退出nano |
   
## **编辑**
 
| 快捷键 | 描述 |
|:--|:--|
| Ctrl+K | 将当前行剪切到剪切缓冲区 |
| Alt+6 | 将当前行复制到剪切缓冲区 |
| Ctrl+U | 粘贴剪切缓冲区内容 |
| Alt+T | 剪切到缓冲区末尾 |
| Ctrl+\] | 补全当前单词 |
| Alt+3 | 注释/取消注释行/区域 |
| Alt+U | 撤销上一个操作 |
| Alt+E | 重做上一个撤销的操作 |
   
## **搜索和替换**
 
| 快捷键 | 描述 |
|:--|:--|
| Ctrl+Q | 开始向后搜索 |
| Ctrl+W | 开始向前搜索 |
| Alt+Q | 向后查找下一个匹配项 |
| Alt+W | 向前查找下一个匹配项 |
| Alt+R | 开始替换会话 |
   
## 删除
 
| 快捷键 | 描述 |
|:--|:--|
| Ctrl+H | 删除光标前的字符 |      
| Ctrl+D | 删除光标下的字符 |
| Alt+Bsp | 删除左侧单词 |
| Ctrl+Del | 删除右侧单词 |
| Alt+Del | 删除当前行 |
  
## 操作

| 快捷键 | 描述 |
|:--|:--|
| Ctrl+T | 执行某个命令 |
| Ctrl+J | 对齐段落或区域 |
| Alt+J | 对齐整个缓冲区 |
| Alt+B | 运行语法检查 |
| Alt+F | 运行格式化器/修复器/整理器 |
| Alt+: | 开始/停止录制宏 |
| Alt+; | 重放宏 |

## 移动

| 快捷键 | 描述 |
|:--|:--|
| Ctrl+B | 向后移动一个字符 |
| Ctrl+F | 向前移动一个字符 |
| Ctrl+**←** | 向后移动一个单词 |
| Ctrl+**→** | 向前移动一个单词 |
| Ctrl+A | 移动到行首 |
| Ctrl+E | 移动到行尾 |
| Ctrl+P | 向上移动一行 |
| Ctrl+N | 向下移动一行 |
| Ctrl+**↑** | 移动到上一个块 |
| Ctrl+**↓** | 移动到下一个块 |
| Ctrl+Y | 向上翻页 |
| Ctrl+V | 向下翻页 |
| Alt+\\ | 移动到缓冲区顶部 |
| Alt+/ | 移动到缓冲区底部 |
  
## 特殊移动

| 快捷键 | 描述 |
|:--|:--|
| Alt+G | 跳转到指定行 |
| Alt+\] | 跳转到匹配的括号 |
| Alt+**↑** | 向上滚动视窗 |
| Alt+**↓** | 向下滚动视窗 |
| Alt+< | 切换到前一个缓冲区 |
| Alt+> | 切换到后一个缓冲区 |
  
## 信息

| 快捷键 | 描述 |
|:--|:--|
| Ctrl+C | 报告光标位置 |
| Alt+D | 报告行/单词/字符计数 |
| Ctrl+G | 显示帮助文本 |
  
## 其他

| 快捷键 | 描述 |
|:--|:--|
| Alt+A | 打开/关闭标记 |
| Tab | 缩进标记区域 |
| Shift+Tab | 取消缩进标记区域 |
| Alt+V | 按原样输入下一个按键 |
| Alt+N | 打开/关闭行号 |
| Alt+P | 打开/关闭可见空白字符 |
| Alt+X | 隐藏或显示帮助行 |
| Ctrl+L | 刷新屏幕 |
